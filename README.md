# Logic Gate Simulator

React frontend with an Express API.

Use Node.js 24.15 or later in the Node 24 line (Node 26 is also supported).

- API: run `npm ci` and `npm start` in this directory (port 5000).
- Frontend: run `npm ci` and `npm start` in `client/` (port 3000).
- Verification: run `npm test` and `npm run build` in `client/`.
- Security: run `npm audit` in this directory and in `client/`.

See [frontend development notes](client/DEVELOPMENT.md) for the Vite migration,
build output, browser support, and automated dependency checks.
